Detailed Description

template<typename TRGB = RGB565, typename StateT = CellState, typename T = DistanceM>
class tinyrobotics::GridMapDisplay< TRGB, StateT, T >

A class that visualizes a GridMap using the TinyGPU display API. This class provides a way to visualize the state of a GridMap on a TinyGPU display. It sets up a callback to update the display whenever a cell state changes, and allows for customization of the color mapping and vehicle sprite.

Dependency: https://pschatzmann.github.io/TinyGPU
