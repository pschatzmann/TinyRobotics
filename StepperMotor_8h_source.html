33/**
34 * @class StepperMotor
35 * @ingroup motors
36 * @brief Stepper motor driver using FastAccelStepper for Arduino.
37 *
38 * This class provides an interface to control stepper motors with acceleration
39 * and speed control. It supports:
40 * - Continuous speed mode: setSpeed(percent) for indefinite movement at a
41 * given speed and direction.
42 * - Relative movement: moveRevolutions(revolutions, speedPercent, callback,
43 * ref) to move a specific number of revolutions, with optional callback on
44 * completion.
45 * - Distance-based movement: moveDistance(distance, wheelDiameter,
46 * speedPercent, callback, ref) to move a specific physical distance (using
47 * wheel diameter), with optional callback.
48 *
49 * You can set pins, maximum speed, acceleration, and steps per revolution. The
50 * motor can be started, stopped, or moved by distance or revolutions.
51 * Acceleration is handled automatically based on the configured accelerationMs.
52 *
53 * The class uses FastAccelStepper's continuous mode for setSpeed(), and
54 * supports asynchronous notification via callback for move operations.
55 *
56 * @dependencies
57 * - Requires the FastAccelStepper library:
58 * https://github.com/ESP32DIYer/FastAccelStepper (Install via Arduino Library
59 * Manager or PlatformIO)
60 * - Uses Arduino core functions (e.g., constrain, map)
61 *
62 * Main methods:
63 * - setPins(stepPin, dirPin, enablePin): Assigns the control pins for the
64 * stepper driver.
65 * - setMaxSpeed(stepsPerSec): Sets the maximum speed in steps per second.
66 * - setStepsPerRevolution(steps): Sets the number of steps per full revolution.
67 * - setAccelerationMs(ms): Sets the time in milliseconds to reach max speed
68 * (acceleration).
69 * - begin(): Initializes the stepper hardware and prepares for movement.
70 * - setSpeed(percent): Starts continuous movement at the given speed percentage
71 * (-100 to 100) using continuous mode.
72 * - moveRevolutions(revolutions, speedPercent, callback, ref): Move the stepper
73 * by a given number of revolutions at a specified speed, with optional
74 * callback.
75 * - moveDistance(distance, wheelDiameter, speedPercent, callback, ref): Move
76 * the stepper by a physical distance (using wheel diameter), at a specified
77 * speed, with optional callback.
78 * - end(): Stops the stepper motor.
79 *
80 * Usage notes:
81 * - Call begin() after setting pins and speed parameters.
82 * - Use setSpeed(percent) to start or change continuous movement. Use
83 * setSpeed(0) to stop.
84 * - Acceleration is set in setSpeed() based on the configured accelerationMs.
85 *
86 * Example usage:
87 * @code
88 * Stepper stepper;
89 * stepper.setPins(2, 3, 4);
90 * stepper.setMaxSpeed(1000);
91 * stepper.setStepsPerRevolution(200);
92 * stepper.setAccelerationMs(2000);
93 * stepper.begin();
94 * stepper.setSpeed(50); // Move at 50% of max speed (continuous mode)
95 * stepper.setSpeed(0); // Stop
96 * stepper.end(); // Ensure motor is stopped
97 * @endcode
98 */
