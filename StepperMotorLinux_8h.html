Detailed Description

Stepper driver for Raspberry Pi (Linux) using hardware PWM.

Only continuous speed mode is supported: the step pin is driven with a PWM signal whose frequency is the step rate, and the direction pin selects the rotation direction. Counted moves (moveRevolutions, moveDistance) and acceleration ramps are NOT supported, because sysfs PWM cannot count steps.

Hardware PWM is available only on BCM pins 12, 13, 18 and 19, which share two PWM channels. Do not use the same channel for a servo and a stepper.
